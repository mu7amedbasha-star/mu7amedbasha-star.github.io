Privacy Policy — Strategy Lab Publisher

Internal tool · last updated 15 October 2026

Strategy Lab Publisher is a private command-line application used only by the owner of the Strategy Lab YouTube channel to manage the channel's own videos.

YouTube API Services

This application uses YouTube API Services. By using it, the owner agrees to be bound by the YouTube Terms of Service. Google's Privacy Policy applies to the Google user data involved: https://policies.google.com/privacy.

Data accessed

The application accesses only the channel owner's own YouTube account through OAuth 2.0 (scopes youtube.force-ssl, youtube.readonly and yt-analytics.readonly), to upload captions and thumbnails, set video metadata and publish times, post the owner's own replies to comments on the channel's videos, and read the channel's own analytics. It does not access, collect or store any data about other users or other channels beyond the public comment text the owner is replying to.

Data storage

OAuth tokens are stored locally on the owner's computer only. No user data is transmitted to any third party, and no data is stored on external servers.

Revoking access

Access can be revoked at any time from https://myaccount.google.com/permissions, which immediately invalidates the stored token.

Contact

Through the Strategy Lab YouTube channel.
